# 🌸 Chaos Sync（混沌同步）

> **蝴蝶效应**: 两只蝴蝶初始仅差0.001，经过足够的时间，通过微弱耦合达到完美同步——混沌中的秩序奇迹。

## 原理

### 什么是混沌同步？

1990年，Pecora和Carroll发现：两个混沌系统可以通过极弱的耦合达到同步。这一发现震惊了整个科学界——混沌系统居然可以同步！

### 蝴蝶效应的悖论

- **分歧**: 初始差0.001，经过几十步后，两只蝴蝶飞行轨迹完全不同
- **同步**: 通过极弱的耦合（0.02），最终两只蝴蝶完美共舞
- **意义**: 这说明混沌虽然对初始条件敏感，但混沌系统之间存在深层的联系

### 物理图像

两个 Lorenz 吸引子在微弱耦合下逐渐趋同：
- 蝴蝶1（粉色）: 初始 (1, 1, 1)
- 蝴蝶2（蓝色）: 初始 (1.001, 1, 1)
- 耦合强度: 0.02（极弱，仅为系统参数的千分之一）

### 关键参数

| 参数 | 物理意义 | 值 |
|------|---------|-----|
| σ | Lorenz参数 | 10 |
| β | Lorenz参数 | 8/3 |
| ρ | Lorenz参数 | 28 |
| κ | 耦合强度 | 0.02 |

### 颜色

- **蝴蝶1轨迹**: 粉红→橙红色渐变
- **蝴蝶2轨迹**: 天蓝→紫色渐变
- **已同步**: 标签变为绿色 "【已同步】"
